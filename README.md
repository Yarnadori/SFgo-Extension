# SFgo Extension

[SFgo](https://sfgo.jp) のライブタイミング画面にラップタイム・セクタータイムのオーバーレイを追加する Chrome 拡張機能です。

## 機能

- **ライブラップタイム表示** — テレメトリデータを補間してリアルタイムにラップ経過時間を更新
- **ラップ確定フラッシュ** — ラップ完了時にタイムを 2 秒間表示
  - 紫: セッションベスト
  - 緑: 自己ベスト更新
  - 黄: 通常ラップ
- **セクタータイムフラッシュ** — 各セクター通過時に累積タイムを表示
- **順位・周回数** — ステアリング表示部に P# / L# を表示

### ソースからビルドする場合

```bash
pnpm install
pnpm build
```

`dist/` フォルダが生成されます。上記手順の 2〜4 で `dist/` を選択してください。

## 開発

```bash
# ファイル変更を監視してビルド
pnpm dev

# 型チェック
pnpm typecheck
```
